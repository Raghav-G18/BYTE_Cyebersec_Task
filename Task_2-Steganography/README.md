# Task 2 — Steganography Challenge

## Objective
Recover the corrupted PNG image and reconstruct a valid image file to make its contents more visible.

## Initial Image
```text
challenge.png
```

The original image could not be opened normally because its PNG structure and image data were corrupted.

## Approach and Methodology

### Step 1: PNG Structure Analysis
I inspected the PNG file at the binary level to identify its image-data chunks and understand why standard image viewers could not open it.

The file contained multiple IDAT chunks, which store the compressed image data. Some structural information and checksum values were corrupted.

### Step 2: Recovering the Compressed Data
I used Python's `struct` and `zlib` modules to extract the available IDAT payloads and decompress the DEFLATE stream without validating the damaged Adler-32 checksum.

The decompressed data contained 1,847,110 bytes. Based on the selected dimensions of 724 × 850 pixels, the expected scanline data size was 1,847,050 bytes. I retained the expected number of bytes and discarded the extra 60 bytes.

### Step 3: Reconstructing the PNG
I examined the scanline filter markers and found 101 invalid markers. I replaced these invalid markers with filter type 0 and rebuilt the image using valid PNG chunks.

The reconstructed image was saved as `final_image.png`.

### Step 4: Verification
I used Pillow to reopen and fully decode the generated image. The verification confirmed that `final_image.png` was a valid, readable PNG file with dimensions of 724 × 850 pixels.

## Final Output

## Tools Used
- Python 3
- Pillow — image loading and validation
- `struct` — binary PNG chunk parsing
- `zlib` — DEFLATE decompression and recompression
- Terminal — running the recovery script
- ChatGPT — guidance on image recovery and debugging

## Key Learnings
- A file can have a valid PNG signature but still be unreadable due to internal corruption.
- PNG images use chunks and scanline filters to store and reconstruct pixel data.
- Recovering a valid file structure does not necessarily restore all damaged image information.
- Verifying the generated image is important to confirm that it can be decoded successfully.
- Preserving the original file makes recovery attempts reproducible and prevents accidental data loss.
