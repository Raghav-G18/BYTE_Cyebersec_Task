# BYTE — Cybersecurity Challenges

## Overview

This repository contains my work on three cybersecurity challenges completed as part of the BYTE task series.

The challenges explore different areas of cybersecurity, including cryptography, steganography, and binary exploitation. Each task involved investigating the provided files, exploring relevant techniques, testing possible approaches, and documenting the methodology.

## Challenges

### Task 1 — Cryptography
Explore encoded ciphertext and classical cryptographic techniques to understand how layered transformations can be reversed.

[View Task 1](./Task_1-Cryptography/)

### Task 2 — Steganography
Investigate a corrupted image file, analyze its internal structure, and explore techniques for recovering readable image data.

[View Task 2](./Task_2-Steganography/)

### Task 3 — Binary Exploitation
Examine a binary program, investigate its execution behavior, and explore the fundamentals of buffer overflows and control-flow redirection.

[View Task 3](./Task_3-Binary_Exploitation/)

## Key Takeaways

Working through these challenges provided practical experience with:

- Analyzing unfamiliar data and file formats.
- Breaking problems into smaller, testable steps.
- Using scripts to automate technical investigations.
- Exploring common cybersecurity concepts and tools.
- Documenting findings clearly and reproducibly.
